================================================================
REPLIT BUILD PROMPT: AI PRODUCT AUDIT FOR TALAHI COLLECTIONS
================================================================

Build a full-stack AI-powered product listing generator called "AI Product Audit" for the
brand Talahi Collections (talahicollections.com). The app analyzes uploaded product images
using OpenAI GPT vision to generate comprehensive, Shopify-compliant product listings. Products
can be published directly to a Shopify store, and the app maximizes AI search engine
discoverability (ChatGPT Shopping, Google AI, Perplexity).

================================================================
TECH STACK
================================================================

Frontend:
- React + Vite
- TailwindCSS
- shadcn/ui component library
- @tanstack/react-query for data fetching
- wouter for client-side routing

Backend:
- Express.js with TypeScript
- multer for file uploads (product images)
- Drizzle ORM with drizzle-zod
- PostgreSQL database (Replit built-in)

AI:
- OpenAI GPT vision (model: gpt-4o or latest vision-capable model)
- Use Replit AI Integrations — no API key needed, use the built-in integration
- Import as: import OpenAI from "openai"; (configured via Replit integration)

Deploy on Replit, port 5000 for both backend and frontend (Vite proxied through Express).

================================================================
BRAND RULES (CRITICAL)
================================================================

- Store brand: Talahi Collections
- Store domain: https://talahicollections.com (Shopify store)
- ALL AI-generated content must use "Talahi Collections" as the brand name

================================================================
DATABASE SCHEMA (shared/schema.ts)
================================================================

Products table (all fields):
- id                serial PRIMARY KEY
- title             text NOT NULL
- description       text NOT NULL
- packaging         text NOT NULL
- handling          text NOT NULL (handling instructions)
- returnPolicy      text NOT NULL
- metaTitle         text NOT NULL
- metaDescription   text NOT NULL
- tags              text[] NOT NULL DEFAULT []
- imageUrl          text            (uploaded image path, e.g. /uploads/...)
- additionalImages  text[] DEFAULT []
- shopifyProductId  text            (set after publishing to Shopify; NULL if not published)
- createdAt         timestamp DEFAULT now()

Create insert schema with drizzle-zod, omitting id and createdAt.

================================================================
AI IMAGE ANALYSIS PROMPT
================================================================

When generating product details from an uploaded image, instruct the AI:

1. Title: Concise, keyword-rich product title (max 255 chars). Include "Talahi Collections" brand.
   Format: "[Descriptive Product Name] - [Category]"

2. Description: Detailed product description (max 5000 chars). Use bullet points.
   Include: what it is, design details, materials/colors, occasion, style keywords, value prop.
   Always brand as Talahi Collections. Never use competitor/supplier brand names. No emojis.

3. Packaging: Packaging details (how it ships/arrives). Use bullet points.

4. Handling Instructions: Care and handling info. Use bullet points.

5. Return Policy: Return/refund policy text. Use bullet points.

6. Meta Title: SEO title for the product page (max 70 chars). Keyword-rich.

7. Meta Description: SEO description (max 320 chars). Compelling, include CTA.

8. Tags: Array of 10-15 relevant keyword tags (max 40 chars each). No duplicates.

Temperature: 0.8 for descriptions, 0.7 for structured fields.

================================================================
SHOPIFY CHARACTER LIMITS
================================================================

- title: 255 chars
- description: 5000 chars
- metaTitle: 70 chars
- metaDescription: 320 chars
- tags: 40 chars each, max 250 total tags

Enforce these limits client-side with color-coded character count indicators:
- Green: under 80% of limit
- Yellow/amber: 80-95% of limit
- Red: over limit

AI DISCOVERABILITY INFRASTRUCTURE
================================================================

All of these endpoints should be publicly accessible (no auth required):

--- CHATGPT MERCHANT FEEDS ---
GET /chatgpt-feed.json
  Returns JSON feed in OpenAI merchant spec format:
  {
    feed_version: "1.0",
    store: { name, url, description },
    products: [
      {
        id: shopifyProductId or "PROD-{id}",
        title,
        description,
        link: shopifyUrl or store URL,
        image_link,
        additional_image_link,
        price: "XX.XX USD",        (from Shopify variant API)
        availability: "in_stock" | "out_of_stock",
        brand: "Talahi Collections",
        product_category,
        enable_search: true,
        enable_checkout: false,
        return_policy,
        shipping: "US shipping available",
        tags
      }
    ]
  }
  Cache Shopify price/inventory data for 10 minutes.

GET /chatgpt-feed.csv
  Same data as /chatgpt-feed.json but as downloadable CSV.
  Content-Disposition: attachment; filename=talahi-collections-chatgpt-feed.csv
  Headers: id, title, description, link, image_link, additional_image_link, price,
           availability, brand, product_category, enable_search, enable_checkout,
           return_policy, shipping, tags

--- LLM CRAWLER FILES ---
GET /llms.txt
  Structured markdown file following llms.txt spec:
  - Store info (brand, URL, location, currency, shipping)
  - Product categories with counts
  - How to buy section
  - Full product list with prices and Shopify URLs
  - Links to all feeds

GET /llms-full.txt
  Complete product details for each product:
  - Brand, URL, Buy Now link, Price, Availability, Category, Image
  - Full description, packaging, handling, return policy, tags
  - About section with pricing range and purchase methods

--- STANDARD FEEDS ---
GET /feed.json     — JSON Feed 1.1 format
GET /feed.xml      — RSS 2.0 format
GET /sitemap.xml   — XML sitemap with all product URLs + images
GET /robots.txt    — Allow all AI crawlers (GPTBot, ChatGPT-User, OAI-SearchBot,
                     Google-Extended, PerplexityBot, CCBot, anthropic-ai, etc.)

--- AI PLUGIN / OPENAPI ---
GET /.well-known/ai-plugin.json   — ChatGPT Actions plugin manifest
GET /.well-known/openapi.yaml     — OpenAPI 3.0 spec for product search API

--- SERVER-RENDERED PRODUCT PAGES ---
GET /product/:id
  Full HTML page with:
  - Meta tags (title, description, keywords, canonical)
  - Open Graph tags including product:price:amount and product:price:currency
  - Schema.org Product JSON-LD with complete Offers object:
    {
      "@type": "Offer",
      price: from Shopify,
      priceCurrency: "USD",
      availability: "https://schema.org/InStock",
      seller: { name: "Talahi Collections", url: "https://talahicollections.com" },
      shippingDetails: { ... addressCountry: "US" },
      hasMerchantReturnPolicy: { description: returnPolicy }
    }
  - FAQPage JSON-LD with 5 questions (what is it, packaging, handling, return policy, where to buy)
  - Organization JSON-LD for Talahi Collections
  - Brand in Product schema: { "@type": "Brand", name: "Talahi Collections" }

GET /products
  Server-rendered product listing page with:
  - ItemList JSON-LD
  - All product cards linking to /product/:id
  - Title: "Talahi Collections - Browse All Products | Indian Sarees, Lehengas & Jewelry"

--- SHOPIFY PRICE CACHE ---
getShopifyProductDataMap() function:
  - Fetches all product variants from Shopify Admin API
  - Returns map: shopifyProductId → { price, compareAtPrice, currency, availability, inventoryQuantity }
  - Cache TTL: 10 minutes
  - Used by: /chatgpt-feed.json, /chatgpt-feed.csv, /llms.txt, /llms-full.txt, /product/:id

--- SHOPIFY HANDLE CACHE ---
getShopifyHandleMap() function:
  - Fetches all product handles from Shopify Admin API
  - Returns map: shopifyProductId → handle (used to build talahicollections.com/products/{handle} URLs)
  - Cache TTL: 10 minutes
  - Supports pagination (250+ products)

IMPORTANT IMPLEMENTATION NOTES
================================================================

1. Image uploads: Use multer, store in /uploads directory, serve statically.
   Allow up to 10 images per product (1 primary + 9 additional).

2. Shopify API version: 2025-01

3. Shopify publish: create product with status "draft", include all images as
   { src: absoluteImageUrl } array. Set vendor to "Talahi Collections".

4. AI generation: encode image as base64 and pass to OpenAI vision endpoint.
   Parse response as JSON with fields: title, description, packaging, handling,
   returnPolicy, metaTitle, metaDescription, tags.

5. Session management: use express-session with SESSION_SECRET for Shopify OAuth state.

6. Caching: both Shopify handle map and price/inventory map use in-memory cache
   with 10-minute TTL. Cache is reset on server restart.

7. SSR pages (/product/:id, /products): these are registered AFTER the Vite middleware
   in development so they take precedence. Pass the price cache function to the SSR
   page renderer.

8. Character count indicators: use conditional className to show green/amber/red
   based on percentage of limit used.

9. All product URLs in feeds point to talahicollections.com/products/{handle}
   when available, falling back to the app's /product/:id URL.

10. robots.txt: allow all major AI crawlers explicitly:
    GPTBot, ChatGPT-User, OAI-SearchBot, anthropic-ai, Claude-Web,
    PerplexityBot, Google-Extended, Googlebot, Bingbot, CCBot
